# SimpleEquity

SimpleEquity is a local Windows app for tracking portfolios, holdings, dividends, watchlists and DCF assumptions.

## Download

Download the latest version from the Releases page:

[Download SimpleEquity](../../releases/latest)

## How to use

1. Download `SimpleEquity-Share.zip`.
2. Extract the zip.
3. Open the extracted folder.
4. Double-click `SimpleEquity.cmd`.

No Codex, Excel, Node.js installation, API keys or private credentials are required.

## Notes

- Windows only.
- The app runs locally on your computer.
- The included `runtime` folder contains Node.js so the app can run without extra setup.
- Automatic price updates may use public StockAnalysis/MarketBeat pages and require internet access.
- This shared version does not include personal portfolio data.

## Disclaimer

SimpleEquity is for informational use only and is not financial advice.
